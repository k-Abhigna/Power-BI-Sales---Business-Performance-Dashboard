## 🔧 How to Build This in Power BI

### Quick Start (30 minutes)
1. Open Power BI Desktop
2. Get Data → Load all 7 CSV files from `data/raw/`
3. Copy/paste Power Query transformations from `power-query/`
4. Create relationships (5 total, all one-to-many)
5. Mark DimDate as date table
6. Create measures from `dax-measures/`
7. You now have a functioning data model! ✅

### Full Dashboard (4-6 hours)
1. Complete above steps
2. Create 6 dashboard pages per `dashboard-design/` specs
3. Add slicers, drill-through, conditional formatting
4. Test and validate all measures
5. Production-ready dashboard ✅
